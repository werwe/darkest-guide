# 다키스트 던전 공략 수첩

다키스트 던전 1을 플레이하면서 바로 찾아보는 한글 인터랙티브 공략 사이트입니다.

- **원정 준비**: 던전 · 길이별 보급품 체크리스트, 주의할 적, 추천 영웅/파티
- **기물 조회**: 던전별 기물에 무엇을 써야 하는지 확률과 함께 표시 (권장 행동 자동 판정)
- **추천 파티**: 상황별 파티, 자리별 대체 영웅 · 스킬 · 장신구
- **영웅 / 보스 / 마을 / 이벤트 / 장신구**
- **용어 사전**: 유저 한글패치와 공식 번역의 용어 차이를 영문 기준으로 정리. 내 게임 용어를 입력하면 사이트 표기가 바뀝니다.

## 실행

빌드 과정이 없습니다. `index.html` 을 브라우저로 열거나 정적 호스팅(GitHub Pages 등)에 그대로 올리면 됩니다.

## 구조

- `index.html`, `css/style.css`, `js/app.js` — 화면
- `js/data/gen.js` — 게임 수치 데이터(스킬, 기물 확률, 장신구, 이미지 주소)
- `js/data/guide.js`, `town.js`, `bosses_a.js`, `bosses_b.js` — 공략 본문

## 출처와 권리

비공식 팬 공략입니다. Darkest Dungeon® 과 게임 내 이미지의 권리는 Red Hook Studios 에 있습니다.
이미지는 저장소에 포함하지 않고 [Darkest Dungeon Wiki](https://darkestdungeon.wiki.gg/) 에서 직접 불러오며, 수치 데이터도 같은 위키를 참고했습니다.

## 화면 인식

오른쪽 아래 **화면 인식** 버튼으로 게임 창을 연결하면, 화면의 글자를 읽어 상황에 맞는 페이지로 이동합니다.

| 게임 화면 | 이동하는 곳 |
|---|---|
| 원정 선택 화면 | 그 던전의 추천 파티 |
| 보급품 구매 화면 | 그 던전 · 길이의 보급품 체크리스트 |
| 탐험 중 기물 이름 | 원정 진행 화면의 해당 기물 |
| 보스 이름 | 보스 공략 |

인식하지 못한 글자는 눌러서 뜻(던전, 길이, 화면 종류, 기물, 보스)을 등록해 두면 다음부터 인식합니다.
글자 인식은 브라우저 안에서만 처리하며(`vendor/tesseract`, Apache-2.0), 화면은 외부로 전송되지 않습니다.
스크린샷을 페이지에 `Ctrl+V`로 붙여 넣어도 같은 방식으로 인식합니다.

### 게임 중에 쓰는 전역 단축키 (크롬 확장)

브라우저는 다른 창에 포커스가 있을 때 키 입력을 받지 못하므로, 게임 중 단축키는 `extension` 폴더의 확장이 담당합니다.

1. 이 저장소를 내려받습니다(Code → Download ZIP 후 압축 해제).
2. 크롬/엣지 주소창에 `chrome://extensions` 를 열고 **개발자 모드**를 켭니다.
3. **압축해제된 확장 프로그램을 로드합니다**를 눌러 `extension` 폴더를 고릅니다.
4. `chrome://extensions/shortcuts` 에서 "게임 화면 인식 실행" 단축키(기본 `Ctrl+Shift+1`)의 범위를 **전역**으로 바꿉니다. 전역 단축키는 `Ctrl+Shift+숫자` 조합만 지정할 수 있습니다.
5. 공략 수첩 탭에서 게임 화면을 연결한 뒤, 게임에서 단축키를 누릅니다.

단축키가 안 될 때는 툴바의 확장 아이콘을 눌러 보세요. 아이콘에 `OK`가 뜨고 오버레이가 열리면 확장은 정상이고 단축키 설정 문제입니다. `탭?`이 뜨면 공략 수첩 탭이 열려 있지 않은 것입니다.

## 오버레이

**오버레이** 화면은 캡처한 게임 화면을 캔버스 장면으로 띄우고, 필요한 정보만 그 자리에 얹어 보여 줍니다. 장면은 PixiJS(`vendor/pixi`, MIT), 영역 편집은 Konva(`vendor/konva`, MIT)로 그립니다. 기획은 [docs/overlay-design.md](docs/overlay-design.md)에 있습니다.

- 원정을 원정 선택 → 영웅 확인 → 보급 → 탐험 네 단계로 보고, 화면을 넘길 때마다 던전·일행·가방 수량을 이어받습니다.

- 메뉴에는 없고, 크롬 확장의 전역 단축키를 누르면 캡처와 함께 열립니다.
- 안내 캐릭터 그림은 눌러서 자기 컴퓨터의 그림 파일로 바꿀 수 있습니다(브라우저에만 저장).
- 페이지 전체를 사용합니다. 세로 모니터에서는 캡처 위쪽에 요약, 아래쪽에 안내 캐릭터와 상세(추천 파티 등)가 채워집니다.
- 보급품 구매 화면: 상점 칸마다 권장 수량
- 원정 선택 화면: 던전 이름표마다 한 줄 요약(누르면 그 던전 선택), 추천 영웅·파티
- 영웅 정보 화면: 그 영웅의 추천 스킬·장신구
- 탐험 중: 기물 이름 옆에 권장 행동
- 던전·영웅을 못 읽으면 위쪽 버튼으로 직접 고릅니다.
- **영역 편집**: 화면 종류별로 "글자를 읽을 곳"과 "칸 위치"를 끌어서 지정합니다. 기본값은 영문 원본 UI 기준이며, 내보내기/가져오기로 공유할 수 있습니다.
- 안내 캐릭터 "까마귀 서기"는 이 사이트를 위해 직접 그린 캐릭터입니다.
