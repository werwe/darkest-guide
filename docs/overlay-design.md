# 오버레이 기획

## 목적

게임을 하는 중에 단축키 한 번으로, 지금 화면에서 필요한 판단만 바로 보여 준다.
찾아보는 공략이 아니라 옆에서 짚어 주는 조수 역할이다.

## 원정 세션

한 번의 원정을 네 단계로 보고, 화면을 넘길 때마다 맥락을 쌓는다.

| 단계 | 게임 화면 | 읽는 것 | 쌓이는 맥락 | 보여 주는 것 |
|---|---|---|---|---|
| 1. 원정 선택 | 지도 | 원정 길이, 던전 이름표 위치 | 던전, 길이 | 던전별 한 줄 요약, 추천 영웅·파티 |
| 2. 영웅 확인 | 영웅 정보 | 영웅 직업 | 이번 일행(최대 4명) | 추천 기술·장신구, 일행 점검 |
| 3. 보급 | 보급품 구매 | 던전, 길이 | 가방 수량 | 상점 칸별 권장 수량 |
| 4. 탐험 | 던전 안 | 기물 이름 | 만난 기물, 남은 수량 | 권장 행동, 가진 아이템 기준 안내 |

- 앞 단계에서 얻은 맥락은 뒤 단계가 그대로 쓴다. 예: 보급 화면에 던전 이름이 없으면 원정 선택에서 고른 던전을 쓴다.
- 글자로 알 수 없는 것(지도에서 고른 던전 등)은 버튼으로 묻는다.
- 단계 표시를 누르면 그 화면으로 고정하고, 다시 누르면 자동 판단으로 돌아간다.
- "새 원정"은 세션을 비운다.

## 화면 구성

- **장면(캔버스)**: 캡처를 배경으로 깔고 정보만 얹는다. 짧은 판단만 둔다(수량, 한 줄 요약, 권장 행동).
- **위 패널**: 지금 화면의 결론. 화면 종류, 제목, 한눈에 볼 수치.
- **아래 패널**: 안내 캐릭터의 한마디와 읽을거리(파티, 일행 점검, 확률 표, 가방).
- 세로 모니터에서는 위아래 여백이 두 패널이 된다.

## 캔버스 장면

PixiJS(WebGL)로 그린다. 층을 나눠 마우스를 따라 서로 다른 폭으로 움직여 깊이감을 준다.

1. 배경: 캡처 화면과 어둡게 덮는 막
2. 효과: 강조할 칸의 테두리(맥박처럼 깜박임), 기물과 카드를 잇는 선, 불티
3. 표시: 수량 배지, 던전 이름표 요약(누를 수 있음), 권장 행동 카드

- 영역 편집은 끌기·크기 조절이 필요해 Konva로 따로 그린다.
- WebGL을 못 쓰면 같은 정보를 HTML로 표시한다.
- 운영체제의 "움직임 줄이기" 설정에서는 움직임 없이 그린다.

## 인식

- 전체 화면을 한 번 읽어 화면 종류를 판단하고, 화면별로 지정한 영역만 다시 읽어 던전·길이·영웅·기물을 얻는다.
- 장식 글꼴이 한두 글자씩 틀리게 읽히므로 비슷한 글자열 매칭을 쓴다.
- 영역 좌표는 영문 원본 UI 기준 기본값이 있고, 영역 편집으로 고쳐 내보낼 수 있다.

## 남은 과제

- 한글 UI와 탐험 중 화면의 실제 캡처로 판단 규칙 보강
- 지도에서 고른 던전을 그림(빛나는 표식)으로 알아내기
- 글자가 없는 기물·적을 그림 대조로 찾기
- 전투 화면 단계(적 이름 → 우선 처치 대상, 보스 기믹)
